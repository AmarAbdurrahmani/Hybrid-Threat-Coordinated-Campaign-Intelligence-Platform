A trained model, not a rule list. It learns every weight from labelled accounts and is tested on accounts it has never seen.

How many bots, how sure, how much to trust it
"Truly bots" = checked against human labels on held-out accounts. The higher the confidence, the more often it is right: that is what a calibrated model looks like.
Gets better with every labelled batch
  1. Collect public comments through the official APIs.
  2. Label: two analysts mark a blind sample bot / human.
  3. Retrain LightGBM + the graph network on all labels so far.
  4. Prove on held-out accounts. A new model replaces the old one only if it scores better.
The Kosovo labelling sheet is the next batch, which turns Kosovo leads into confirmed numbers.
